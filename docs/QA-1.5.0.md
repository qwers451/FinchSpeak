# QA FinchSpeak 1.5.0

## Пакеты 4–5

Автоматическая проверка выполнена в отдельной ветке `codex/1.5-ui`. Ручную приёмку собранного клиента проводит владелец. Приложение в ходе этой работы не запускалось.

### Проверено автоматически

- Контекстное меню на плитке, строке голосовой комнаты и строке панели участников. Правый клик, Context Menu, Shift+F10, кнопка действий.
- Стрелки, Home/End, Enter/Space, переход в подменю и обратно, Esc с возвратом фокуса. Закрытие при внешнем клике, прокрутке, resize и потере фокуса окна. Геометрия у границ проверена с заданными размерами элементов.
- Локальный мут по ID пользователя, восстановление прежней громкости, переподключение с новым peer ID и одновременные устройства. Звук экрана сохраняет отдельную громкость.
- Повторная проверка прав перед модерацией. Перенос между комнатами с проверкой ID пользователя, peer ID, исходной комнаты и прав. Некорректный, устаревший, файловый и сброс в исходную комнату отклоняются.
- Сохранённый порядок плиток, новая плитка в конце, своя плитка первой и приоритет говорящих при числе участников больше 12. Вставка перед/после по половине целевой плитки.
- Select с клавиатурой, пропуском недоступных вариантов, возвратом фокуса, Esc, внешним кликом и заданными размерами у края окна. Отключённое выбранное устройство сохраняет имя и предупреждение.
- `npm test -- --maxWorkers=2` — 64 файла, 579 тестов прошли. `npm run build` — успешно.
- В предыдущем полном прогоне `moduleGraph.test.ts` превысил лимит 5 секунд при импорте App. Изолированный повтор и полный прогон с двумя рабочими процессами прошли.
