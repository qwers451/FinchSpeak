# Отклонения от дизайн-системы

Каждое отклонение от артбордов Claude Design записывается здесь с причиной.

| Дата | Экран | Что изменено | Почему |
|---|---|---|---|
| 2026-10-16 | Все | Шрифты Nunito/Inter лежат локально (`public/fonts`), а не грузятся с Google Fonts | Приложение работает без интернета, CSP запрещает внешние источники |
| 2026-10-16 | Заголовок окна | Кнопки окна — настоящие `<button>`, окно без системной рамки (`decorations:false`) | Нужна доступность с клавиатуры и перетаскивание через `data-tauri-drag-region` |
| 2026-10-16 | Поля ввода | Макеты рисуют `.input` как `<span>`; в приложении внутри `.input` настоящий `<input>` с той же отрисовкой | Макеты статичны |
| 2026-10-16 | Тексты | Язык интерфейса — английский, как в макетах | Единый язык с дизайном; перевод — отдельная задача |
| 2026-10-16 | C2 · вложения | Вместо процентов загрузки — «Uploading…» со спиннером | Файл уходит в один запрос через Tauri IPC; реальный прогресс потребовал бы потоковой отправки, это отдельная задача |
| 2026-10-16 | C1 · шапка канала | Поле «Search» и кнопка «Members» пока не показаны | Поиск делается в M5 (B4.5); список участников всегда справа |
| 2026-10-16 | C1 · подсказка о реакциях | Подсказка со списком людей — на `:hover`/`:focus` самой реакции, без отдельной всплывашки «and 11 others» с аватарами | Достаточно для 50 человек; текст «Имя, Имя и N других» |
| 2026-10-16 | D1 · LIVE-карточка | На карточке — заставка с птицей и меткой LIVE, а не живое превью экрана; нет «3 watching» | Сервер не получает картинку от показывающего, пока нет подписчиков; делать для этого отдельный канал превью ради карточки не стоит. Живые превью есть в выборе экрана у самого показывающего |
| 2026-10-16 | E2 · плашка «Вы в эфире» | Нет счётчика зрителей и нет переключателя звука во время показа; плашка внутри главного окна | Сервер не сообщает число зрителей; звук выбирается до старта (решение владельца: плашка внутри окна) |
| 2026-10-16 | D3 · проверка микрофона | «Проверить микрофон» и живой уровень работают только внутри голосовой комнаты | Микрофон открывается только во время звонка (одно устройство, один поток) |
| 2026-10-16 | Автообновление | Своё обновление вместо `tauri-plugin-updater`: манифест `latest.json` на GitHub Releases, проверка подписи minisign, запуск установщика | Плагин зависит от `zip` 2.x/4.x, а все эти версии отозваны (yanked) в реестре: сборка невозможна. Подпись и ключ те же (формат `tauri signer`), проверка — в `app/src/updater.rs` с тестами |
| 2026-10-16 | Сообщения ОС | Нажатие на уведомление не открывает канал | `tauri-plugin-notification` на Windows не отдаёт событие нажатия; уведомление показывает автора и канал |
