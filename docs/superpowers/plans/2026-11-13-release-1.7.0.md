# FinchSpeak 1.7.0 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Семь функций, выбранных владельцем: саундборд, голосовые сообщения, панель здоровья сервера, «Позвать стаю», мини-окно поверх игры, уведомления Windows с аватаром и кнопками, птичьи и мягкие звуки.

**Architecture:** Основа — `main` после 1.6.1. Новые управляющие сообщения идут только клиентам с `client_level >= 170`, наличие функций сервер объявляет в `ServerState.features` — так же, как это сделано для музыки в 1.6. Саундборд передаёт по сети только команду, звук играется локально у каждого.

**Tech Stack:** Rust (Tokio, Quinn, Axum, SQLx/SQLite, sysinfo, tauri-winrt-notification), Tauri 2, SolidJS + TypeScript, Vitest, Web Audio API.

**Spec:** этот документ (решения ниже окончательные). Образцы: [план 1.6.0](2026-11-12-release-1.6.0.md) и спецификация [1.5/1.6](../specs/2026-11-09-release-1.5.0-design.md), раздел 0.1 (совместимость) и 7 (синхронная музыка).

## Решения

| Функция | Решение |
| --- | --- |
| Саундборд | Общая доска сервера: до 48 звуков, каждый до 5 с, хранится как WAV 24 кГц моно (как звук входа). Нажатие отправляет серверу `PlaySound { sound_id }`, сервер рассылает его комнате, **каждый клиент играет звук сам** из кэша. В голос ничего не подмешивается: нет перекодирования, нет эха, работает личный мут и громкость. Загружает любой участник, удаляет автор или персонал. Не чаще одного звука в 3 с на человека; заглушённый модератором играть не может. |
| Голосовые сообщения | Запись нативно через уже настроенный микрофон с шумоподавлением (не через браузер), Ogg/Opus 32 кбит/с, до 2 мин. Отправляется обычным вложением; к вложению добавляются длительность и волна (64 значения). В чате — плеер с волной и скоростью 1× / 1,5× / 2×. |
| Панель здоровья | Вкладка «Здоровье» в админке: процессор и память процесса, память системы, лимит контейнера (если есть), свободный диск под данными, размер базы, вложений и музыки, сессии, люди в голосе, трафик в обе стороны, потерянные датаграммы, время работы. Замер раз в 5 с, история за час в памяти сервера, графики-спарклайны. Предупреждения: память выше 85 % лимита, диск меньше 1 ГБ. |
| Позвать стаю | Кнопка в шапке комнаты «Позвать за собой» → выбор комнаты. Вы перелетаете сразу, остальным приходит карточка «{name} зовёт в {room}» с кнопками «Лететь» и «Остаться», она исчезает через 30 с. Плюс пункт «Позвать сюда» в меню участника для человека в сети, но не в вашей комнате. Не чаще одного зова в 10 с. |
| Мини-окно | Второе окно Tauri: без рамки, полупрозрачное, всегда сверху, не в панели задач. Показывает людей вашей комнаты: аватар, имя, кто говорит, микрофон выключен. Перетаскивается, положение и прозрачность запоминаются, режим «клики насквозь». Включается кнопкой в доке, пунктом трея и горячей клавишей; опция «показывать автоматически во время игры» (по уже работающему определению игры). Поверх эксклюзивного полноэкранного режима игр Windows окна не показывает — в подсказке: оконный режим без рамки. |
| Уведомления Windows | Системные уведомления становятся богаче: аватар отправителя (круглый), заголовок и текст, клик открывает FinchSpeak на нужном канале или комнате. О чём: упоминания **и ответы на ваши сообщения**; зов стаи и «Позвать сюда» — **с кнопками «Лететь» и «Остаться» прямо в уведомлении**, отвечать можно не выходя из игры; кто-то вошёл в вашу комнату; кто-то начал демонстрацию в вашей комнате. Показываются, только когда окно FinchSpeak не в фокусе; не показываются в «Не беспокоить» и для заглушённых каналов. Каждый тип включается отдельно в **Настройки → Уведомления**. Делаются напрямую через WinRT-уведомления (крейт `tauri-winrt-notification`, он уже есть в проекте как зависимость плагина), потому что плагин Tauri не сообщает о кликах и не умеет кнопки. |
| Звуки | Все тоны мягче: атака 25 мс вместо 10, пик 0,18 вместо 0,3, синус через фильтр низких частот 2,4 кГц, ноты на кварту ниже. Новый набор **«Птицы»** — синтезированные щебеты (частотные свипы с вибрато), без звуковых файлов. Выбор в **Настройки → Уведомления → Звуки**: «Птицы» (по умолчанию) или «Мягкие». Стандартный звук входа (если свой не загружен) — из выбранного набора. |

## Global Constraints

- Ветка `feat/1.7.0` от `origin/main`, рабочая копия `C:\Users\Михаил\Documents\GitHub\FinchSpeak-stream`. Rust — только из PowerShell: `. "C:\Users\Михаил\Documents\GitHub\FinchSpeak-stream\target\dev-env.ps1"; cargo …`; не запускать две cargo-команды одновременно, не делать `cargo clean`.
- Пять проверок перед каждым коммитом: `cargo check --workspace --all-targets --locked`, `cargo test --workspace --locked -- --test-threads=1`, `cargo clippy --workspace --all-targets --locked -- -D warnings`, в `app/frontend` — `npm test` и `npm run build`.
- Без `unwrap()/expect()/todo!()` вне тестов в сетевом, серверном и аудио-коде; `finch-server` не зависит от `finch-audio`, `finch-screen`, `finch-client-core`; в колбэках cpal — без блокировок, аллокаций и ввода-вывода.
- Протокол: новые поля — `#[serde(default)]`; новые варианты `ServerMessage` — только при `client_level >= CLIENT_LEVEL_1_7` (= 170); функции объявляются в `ServerState.features`: `"soundboard"`, `"voice-messages"`, `"flock"`, `"health"`. Клиент без нужной функции у сервера прячет её интерфейс.
- Все строки через `t()` с русским переводом; стили по `docs/UI-STYLES.md`; каждая функция работает в темах «Снегирь», Claude Dark, Finch Custom, «Своя» и в режиме Finch.
- Ограничения частоты — на сервере, по образцу `SessionManager::allow_action`.
- Один пункт — один коммит, тест первым; коммиты заканчиваются строкой `Co-Authored-By: <модель исполнителя>`.

## Review Focus

1. **Старый клиент на новом сервере во время саундборда и зова.** Клиент 1.6 не получает `SoundPlayed`/`FlockCall` и не падает — тест в Task 1.
2. **Спам саундбордом и зовами.** Второй звук раньше 3 с и второй зов раньше 10 с отклоняются без рассылки — тесты в Task 3 и Task 5.
3. **Голосовое сообщение длиннее 2 мин или при отключённом микрофоне.** Запись обрывается ровно на 2:00 и отправляется; без устройства ввода — понятная ошибка, а не пустой файл — тесты в Task 7.
4. **Уведомление о зове, когда человек уже сам ушёл в эту комнату, и клик по уведомлению после закрытия окна.** Кнопка «Лететь» не переподключает того, кто уже в комнате; клик открывает и разворачивает окно из трея — тесты в Task 10.
5. **Панель здоровья вне Docker и на Windows.** Без cgroup лимит контейнера показывается как «нет», а не как ошибка; диск считается для папки данных — тест в Task 4.
