## Review Focus

1. **Пакет потерян, следующий тоже потерян (двойная потеря).** FEC восстанавливает только один пропуск; на втором — обычный PLC без паники и без рассинхрона счётчиков — тест в Task B1.
2. **Тихий голос рядом с громким.** Лимитер не трогает сигнал ниже 0,8 и не даёт выйти за ±1 даже при сумме трёх громких говорящих — тест в Task B2.
3. **Медленный, но честный клиент на плохой сети (поток демонстрации 10 Мбит/с с пиками).** Ограничение SFU не режет обычный трафик демонстрации 60 FPS — тест в Task C1.
4. **Пользователь с правильным паролем после чужих неудачных попыток с того же IP (общий NAT).** Блокировка по IP мягкая: 20 попыток за 10 минут, а не вечный запрет — тест в Task C6.
5. **Повторное открытие настроек и выбор в выпадающем списке внутри модального окна.** Выбор применяется и сохраняется с первого клика — тест в Task A1.

## Phase C. Безопасность сервера

### Task C1: Ограничения медиа-трафика в SFU
