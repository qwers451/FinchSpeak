# FinchSpeak 1.2.0 Implementation Plan

> **For agentic workers:** Use executing-plans with bounded parallel work explicitly authorized by the owner. Track evidence in target/desktop-1.2.0/progress.md.

**Goal:** Ship two production desktop designs, RU/EN and verified microphone preview fixes as stable v1.2.0.
**Architecture:** Preserve SolidJS and Tauri commands. Theme-scoped semantic tokens and component styles; explicit reactive localization; local preview lifecycle isolated from network transmission.
**Tech Stack:** SolidJS, TypeScript, CSS, Rust/Tauri, existing WebRTC/RNNoise.
**Spec:** docs/superpowers/specs/2026-10-17-desktop-1.2.0-design.md

## Global Constraints
- Default claude/ru, persistent custom/en options, preserve old profile data.
- Reproduce supplied custom visual identity; no framework migration, fake data or unsupported controls.
- One voice enhancement toggle, no new DSP profiles. Test audio never becomes public audio.
- Respect reduced motion and keyboard access. Stable v1.2.0 publication authorized.

## Review Focus
- Corrupt/old saved preferences recover without losing unrelated values (Task 1).
- Language switching updates already mounted dialogs and preserves dynamic names (Task 1).
- Test completion/cancel/device failure restores effective monitoring and keeps privacy (Task 2).
- Custom clipping never hides menus/focus; narrow windows keep important controls (Task 3).
- Packaged/default locale and assets work offline and updater signatures are valid (Task 4).
