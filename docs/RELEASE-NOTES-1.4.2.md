# FinchSpeak 1.4.2

- На Windows демонстрация экрана использует Windows Graphics Capture. Сессия захвата передаёт новые кадры по мере изменений на экране. Если сессию открыть не удаётся, приложение переключается на захват отдельными снимками.
- Появился режим 60 кадров в секунду: переключатель «Частота кадров» в окне выбора экрана, выбор запоминается. В этом режиме картинка ограничена 1080p. Если компьютер не успевает кодировать, демонстрация сама переходит на 30 кадров и сообщает об этом.
- Во время демонстрации видно частоту отправки кадров и битрейт видео.
- У зрителя приложение передаёт кадры в интерфейс двоичными данными, сокращая работу по их обработке.

## Обновление

После публикации версии на Windows откройте **Настройки → Клавиши и о программе → Обновления** и нажмите **Установить 1.4.2**. FinchSpeak скачает подписанный установщик. Клиент совместим с сервером 1.4.1.
