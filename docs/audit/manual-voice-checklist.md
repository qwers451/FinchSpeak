# Ручной чек-лист голоса (≈ 10 минут, одна машина)

Закрывает то, чего не видит стенд: драйверы, `cpal`, реальные микрофон и наушники, сам интерфейс.
Перед началом соберите ветку `audit-and-testbed`, запустите `Run_Server.bat`, затем **два** экземпляра клиента
(`Run_FinchSpeak.bat` дважды) и войдите под двумя разными пользователями — назовём окна **A** и **B**.

Отметьте результат у каждого пункта: ✅ как ожидалось / ❌ иначе (опишите, что видно).

## Перед началом: частоты устройств

Панель управления → Звук → вкладки «Воспроизведение» и «Запись» → устройство по умолчанию → Свойства → Дополнительно.

| Устройство | Частота | Результат |
|---|---|---|
| Микрофон по умолчанию | | |
| Наушники/динамики по умолчанию | | |

Если частота не 48 000 Гц, искажения звука ожидаемы и вызваны уже известными ошибками: микрофон — AUD-048, вывод — AUD-051 (16 и 96 кГц). Это не регресс рефакторинга. Для чистой проверки пункта 0 по возможности выставьте 48 000 Гц.
