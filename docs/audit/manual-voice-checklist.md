# Ручной чек-лист голоса (≈ 10 минут, одна машина)

Закрывает то, чего не видит стенд: драйверы, `cpal`, реальные микрофон и наушники, сам интерфейс.
Перед началом соберите ветку `audit-and-testbed`, запустите `Run_Server.bat`, затем **два** экземпляра клиента
(`Run_FinchSpeak.bat` дважды) и войдите под двумя разными пользователями — назовём окна **A** и **B**.

Отметьте результат у каждого пункта: ✅ как ожидалось / ❌ иначе (опишите, что видно).

## 0. Регресс после рефакторинга (обязательно)

Фаза 2 перенесла голосовой захват в `finch_audio::VoiceCapture` и сетевой клиент в `finch-client-core` без изменения поведения. Этот пункт проверяет, что ничего не сломалось.

| # | Действие | Ожидание | Результат |
|---|---|---|---|
| 0.1 | Вход в A и B | Оба входят, список каналов виден | |
| 0.2 | Сообщение из A в `#general` | Появляется в B сразу | |
| 0.3 | A и B входят в «General Voice», говорить в микрофон | В B слышно A (голос из своих же наушников с задержкой) | |
| 0.4 | Говорить и молчать | Индикатор речи A загорается и гаснет | |

## 1. Тест-петля «слышу себя»

**Недоступно в приложении — AUD-042, подпроект 2.** Замена: пункт 0.3 (второй экземпляр клиента слушает первый).

## 2. Смена устройства ввода и вывода

**Недоступно — AUD-024, подпроект 2:** приложение всегда открывает устройства по умолчанию Windows. Замена:

| # | Действие | Ожидание | Результат |
|---|---|---|---|
| 2.1 | Узнать частоту микрофона: Панель управления → Звук → Запись → Свойства → Дополнительно | Записать значение (например, 48 000 или 44 100 Гц) | |
| 2.2 | Если частота не 48 000 Гц — в 0.3 послушать голос | Ожидаемо «рваный» голос со щелчками — это AUD-048 | |
| 2.3 | Во время звонка выдернуть или выключить гарнитуру | Ожидаемо звук пропадает до перезахода — AUD-024 | |

## 3. Шумоподавление

| # | Действие | Ожидание | Результат |
|---|---|---|---|
| 3.1 | Молчать при включённом вентиляторе или стуке клавиатуры | В B шум заметно тише, чем в реальности | |
| 3.2 | То же, смотреть на индикатор речи A в B | Возможно ложное срабатывание — AUD-050 | |
| 3.3 | Говорить при включённом фоновом видео с речью | Фоновая речь не подавляется — ожидаемо, AUD-049 | |

## 4. Mute / deafen и индикатор речи

| # | Действие | Ожидание | Результат |
|---|---|---|---|
| 4.1 | Mute в A, говорить | В B тишина, индикатор не горит | |
| 4.2 | Deafen в B | B не слышит A | |
| 4.3 | Снять deafen в B | B снова слышит A; микрофон B остаётся выключенным — AUD-033 | |
