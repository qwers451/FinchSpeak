# FinchSpeak 1.6.2

Этот выпуск заменяет 1.6.1, который не был опубликован, и включает всё из [1.6.1](RELEASE-NOTES-1.6.1.md) и [1.6.0](RELEASE-NOTES-1.6.0.md).

- Иконка приложения, установщика и трея: птица на тёплой песочной плитке с мягкой тенью — теперь она хорошо видна и не сливается с фоном.
- Видеокодер демонстрации экрана снова собирается с ассемблерными ускорениями.

## Обновление

На Windows откройте **Настройки → Клавиши и о программе → Обновления** и нажмите **Установить 1.6.2**. Сервер 1.6.1 подходит, обновлять его не нужно.
