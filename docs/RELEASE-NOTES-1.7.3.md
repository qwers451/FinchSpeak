# FinchSpeak 1.7.3

Исправление выпуска 1.7.2, только интерфейс. Сервер и протокол не менялись: клиент 1.7.3 работает с сервером 1.7.1 и 1.7.0.

## Исправления

- Значки музыки, саундборда, демонстрации экрана и плеера снова видны. В 1.7.2 собранное приложение искало их по неверному пути и показывало пустые места.
- Кнопка «⋯» у участника в правой панели больше не съезжает вниз при наведении и остаётся в своей строке.
