# Диагностическая сборка локального аудио

Цель — различить захват, DSP, расписание worker и воспроизведение на проблемном Windows 11, где локальные preview прерываются, а Windows Recorder/Discord работают нормально. Не объявляет конкретную первопричину ноутбука установленной.

Диагностика opt-in. В callbacks только локальные счётчики, измерение времени и atomics; mutex, файловые операции, сериализация и новые allocations не добавлены. Накопленные счётчики обновляются в коротких atomic секциях. При reset/stop control thread отделяет измерительные эпохи и ждёт только эти короткие секции; старые DSP/batch измерения и callback timestamps новой эпохе не приписываются.

Worker делает до 120 снимков технических счётчиков, примерно один в секунду, с режимом preview и конфигурацией потока. Конфигурация, успешное открытие и остановка различаются; поколения отмечены. Счётчики накопительны с начала диагностики, в том числе между сменами устройств. После stop отчёт и длительность фиксируются. JSON сериализуется вне history lock. Callback не читает history. Аудиосигнал и privacy gate диагностикой не меняются.

Независимое ревью Astra выявило неоднозначное название VAD-счётчика, смешение конфигураций устройств и измерительных эпох. Все три замечания исправлены и повторное ревью не нашло блокеров. Activation rejection теперь явно считается до preroll и включает отдельный PTT-счётчик. Живые конфигурации отделены от frozen report, есть generation/active flags. Epoch/writers protocol защищает reset от запоздалых измерений.

Окончательные локальные проверки версии 1.2.3:

- `finch-app`: 50 unit + 3 integration — PASS, два физических теста микрофона явно пропущены.
- Frontend: 294 теста в 35 файлах — PASS; TypeScript и production build — PASS.
- Clippy `finch-app --all-targets --locked --offline -- -D warnings` — PASS.
- Тесты проверяют opt-in/reset/stop, bounded history, callbacks/DSP histogram, отсутствие payload/секретных полей в JSON, заморозку конфигурации и отбрасывание старой эпохи; frontend — start/reset/stop, errors и выгрузку Blob с освобождением URL.

Логи: `target/audio-network-qa/diagnostics-{app-final,clippy,frontend-tests,frontend-build}.log`.
