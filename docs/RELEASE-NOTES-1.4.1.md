# FinchSpeak 1.4.1

- В настройках профиля можно выбрать свой звук входа в голосовую комнату длительностью до двух секунд. После смены аватара FinchSpeak предлагает тему под его цвета.
- В списке голосовых комнат видно, кто говорит и кто демонстрирует экран. Модераторы могут перемещать участников между голосовыми комнатами.
- Демонстрация переживает кратковременное сворачивание окна. При возвращении к просмотру видео восстанавливается с нового ключевого кадра.

## Обновление

На Windows откройте **Настройки → Клавиши и о программе → Обновления** и нажмите **Установить 1.4.1**. FinchSpeak скачает подписанный установщик. Для звуков входа и перемещения участников нужен сервер версии 1.4.1.
