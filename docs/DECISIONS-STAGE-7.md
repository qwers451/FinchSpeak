# Согласованные решения для этапа 7 и «прод-версии»

Дата: 2026-10-16. Решения владельца, которые закрывают вопросы из [PLAN-STAGE-7.md](PLAN-STAGE-7.md). Работа идёт по всему плану **без дополнительных подтверждений**; ниже границы этой автономии.

## Решения по продукту

| Вопрос | Решение |
|---|---|
| Скачивание шрифтов Nunito/Inter (woff2, OFL) и NSIS | **Разрешено.** Шрифты лежат в репозитории (`app/frontend/public/fonts`), NSIS ставлю локально для сборки установщика |
| Роль модератора | **Да.** Матрица прав в `permissions.rs` (модератор: кик, server mute, удаление чужих сообщений, чтение журнала; админ: всё остальное) |
| Плашка «Вы в эфире» | **Внутри главного окна** (не отдельное окно). Это не мешает проверке: плашка видна, пока окно открыто; свёрнутое в трей окно показывает красную точку на значке трея |
| Закрытие окна крестиком | **Сворачивать в трей**; выход — из меню трея и из настроек («Закрывать в трей» переключается) |
| Пароль | **Запоминаются только адрес и логин**; пароль нигде не хранится. Повторный вход после перезапуска — по сохранённому токену до его истечения (72 ч), иначе форма с заполненным логином |
| Превью ссылок | **Не делаем вообще.** Ссылки кликабельны, сервер на них не ходит. Прямые картинки по ссылкам тоже не разворачиваются (меньше риска) |
| Автообновление | **GitHub Releases, ключ подписи у владельца.** Я генерирую пару ключей минисайн: публичный ключ идёт в конфиг приложения, приватный отдаётся владельцу и в репозиторий не попадает |
| Подпись кода (Authenticode) | **Не покупаем.** Установщик покажет SmartScreen; в README описано «Подробнее → Выполнить в любом случае» |
| Звуки уведомлений | **Синтезированные тоны** (генерируются кодом, файлов не скачиваем) |
| Эталоны для сверки с дизайном | **На моё усмотрение**: я делаю скриншоты приложения по экранам, оцениваю их по дизайн-системе и навыкам дизайна и принимаю эталоном; дальше сверяю с ними |
| Если элемент дизайна рискован | **Дизайн меняю так, чтобы всё работало.** Приоритет — рабочая прод-версия. Каждое отклонение записываю в `docs/design-deviations.md` |

## Что считается прод-версией

Выпуск готов, когда выполнено всё:

1. Все автотесты зелёные (Rust, frontend), clippy `-D warnings`, сборка клиента и сервера из чистого дерева.
2. **Клинический прогон:** пакет собран с нуля, развёрнут из архива, пройдены все сценарии двумя клиентами (вход, чат, голос, показ экрана со звуком, админка, профиль, переподключение, бэкап и восстановление).
3. **Нагрузочный прогон на 50 клиентов:** чат, голос и показ экрана одновременно; замеры CPU, памяти, задержки, доставки; результаты в `BASELINE.md`.
4. **Повторный аудит безопасности** сервера и клиента (авторизация, права, ввод, файлы, TLS, зависимости `cargo audit`/`npm audit`); найденное исправляется до релиза.
5. Что требует ушей, глаз, второго компьютера, чистой Windows или Docker, **выносится в чек-лист владельцу** и не объявляется проверенным.

## Границы автономии

| Действие | Разрешено |
|---|---|
| `git push origin main` | **Да, после каждой вехи M1–M6**, когда всё зелёное. Между вехами коммиты остаются локальными |
| Тег `v1.0.0` и запуск релизного workflow | **Да, в конце**, без публикации секретов. Приватный ключ обновлений владелец добавляет в секреты GitHub сам |
| Перезапуск сервера и клиентов на этой машине | **Да** |
| Рабочая база `finchspeak.db` (аккаунт `alice`) | **Можно использовать для живых проверок.** Правила: перед работой копия базы и `data/` в `backups-manual/`; тестовые пользователи и сообщения создаются с префиксом `test` и удаляются после проверки; аккаунт `alice` и его данные не меняются |
| Нагрузочный прогон и аудит без предупреждения | **Да** (только localhost, возможна заметная нагрузка на несколько минут) |

## Что остаётся за пределами автономии

- Приватный ключ подписи обновлений (создаёт и хранит владелец).
- Всё, что требует реального слуха или чужой машины (раздел 8 чек-листа).
- Покупки, учётные записи на внешних сервисах, платные сертификаты.
- Удаление чужих данных и любые необратимые действия вне репозитория и временных каталогов.
