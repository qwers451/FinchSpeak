# FinchSpeak 1.7.1

## Интерфейс и чат

- Исправлен выбор набора звуков в настройках и обрезка страницы «Внешний вид».
- Меню и выпадающие списки сохраняют кликабельность при анимациях и прокрутке соседних панелей.
- Плеер и саундборд открываются отдельными окнами внутри приложения; инструменты комнаты находятся в левой панели.
- Улучшены вёрстка плеера, длинные подписи и компактный режим Finch.
- Сообщение сохраняет один элемент списка при подтверждении сервером. Совпадающие клиентские ID разных авторов не удаляют своё исходящее сообщение.
- Голосовые сообщения завершаются при отпускании кнопки; отменённая запись и смена канала не отправляют запись в другой чат.
- Добавлены черновики по каналам, переход к последним сообщениям и правка последнего своего сообщения клавишей ↑.

## Звук

- Громкость участника, музыки и саундборда меняется по кривой восприятия; ползунки участника показывают одно актуальное значение.
- Улучшено восстановление потерянных пакетов Opus FEC, адаптация джиттер-буфера и ожидаемых потерь.
- Голос использует битрейт комнаты. Тихий сигнал проходит без искажений, громкие пики ограничиваются мягким лимитером.
- Улучшены стереозвук демонстрации и выбор поддерживаемого формата аудиоустройства.

## Сервер

- Ограничены медиатрафик, запросы управления и неподтверждённые подключения; запас для пиков демонстрации составляет 1 МиБ.
- Ненужные ключевые кадры отклоняются до чтения тела; параллельное чтение, удержание кадров при отправке и создание превью ограничены. Зависшие отправки зрителям прекращаются по тайм-ауту.
- Загрузка и скачивание файлов выполняются потоками, добавлены квоты и ограничения частоты загрузок.
- Argon2 работает вне асинхронного runtime с ограничением параллельности; вход ограничивается по IP.
- Приватные ключи, JWT-секрет и резервные копии получают закрытые права на Unix.
- CORS разрешает адреса приложения и явно заданные `[server] allowed_origins`. SmartScreen во встроенном браузере снова включён.

## Обновление сервера

Клиенты и серверы 1.7.0 и 1.7.1 совместимы; новых миграций базы данных нет.

Перед обновлением проверьте сумму сохранённых вложений каждого пользователя: квота по умолчанию — 1024 МиБ, существующие файлы учитываются. При необходимости увеличьте `[storage] user_quota_mb`.

В Docker сервер работает как UID/GID 10001. Если файлы `key.der`, `jwt_secret` или резервные копии ранее принадлежали root, перед запуском передайте их пользователю контейнера; приватные файлы должны иметь права 0600. Сохраните резервную копию базы и каталога данных.

Развёртывание на VPS выполняется отдельно после подтверждения владельца.
