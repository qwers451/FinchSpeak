# FinchSpeak 1.6.1

Этот выпуск включает всё из [1.6.0](RELEASE-NOTES-1.6.0.md): плавную демонстрацию экрана, общий музыкальный плеер комнаты, меню участника, перетаскивание людей между комнатами, статус игры и пять анимаций речи.

## Новый облик

- Новый логотип: птица в наушниках. Он на иконке приложения и установщика, в трее, в боковой панели, на экране входа и на пустых экранах.
- Иконка в трее одна для всех состояний; состояние, как и раньше, показывает цветная точка: в комнате, говорите, микрофон выключен, демонстрация экрана.
- Новая тёмная тема **Снегирь** в цветах логотипа: сливочный текст, оранжевые акценты. После обновления она включается у всех один раз; вернуть прежнюю тему можно в **Настройки → Внешний вид → Тема**, выбор запоминается.

## Обновление

На Windows откройте **Настройки → Клавиши и о программе → Обновления** и нажмите **Установить 1.6.1**. Для музыки, статуса игры и списка участников не в сети нужен сервер 1.6.x; со старым сервером клиент работает, а эти функции скрыты.
