# FinchSpeak 1.6.3

Этот выпуск заменяет 1.6.1 и 1.6.2, которые не были опубликованы, и включает всё из [1.6.1](RELEASE-NOTES-1.6.1.md) и [1.6.0](RELEASE-NOTES-1.6.0.md).

- Иконка приложения, установщика и трея: птица на тёплой песочной плитке с мягкой тенью — теперь она хорошо видна и не сливается с фоном.
- Сборку релиза останавливала проверка видеокодера: после обновления Rust она искала файлы по старому пути. Проверка исправлена и по-прежнему не пропустит выпуск, если видеокодер собран без ассемблерных ускорений.

## Обновление

На Windows откройте **Настройки → Клавиши и о программе → Обновления** и нажмите **Установить 1.6.3**. Сервер 1.6.1 подходит, обновлять его не нужно.
