# FinchSpeak1.1.0

- Голос выравнивает оригинальный WebRTC AGC2: тихая речь становится громче, пики ограничиваются. Сохраняются RNNoise, эхоподавление AEC3 и передача Opus.
- В Voice and audio появился один переключатель **Voice enhancement**, включённый по умолчанию. Ручная громкость микрофона и порог речи сохраняются. Отключение возвращает прежний тракт с шумоподавлением и AEC.
- Закрытый PTT, mute и проверка микрофона очищают историю частного звука перед возобновлением передачи.
- Сервер1.0.1 совместим с новым клиентом. Формат голосовых пакетов и база данных не менялись.
- Windows-пакеты содержат необходимую нативную библиотеку и уведомления о лицензиях.

Настройка: войдите в голосовой канал → кнопка настроек внизу → **Voice and audio** → **Voice enhancement**. Сначала оставьте Input volume100%, подберите Speech threshold по индикатору, затем проверьте микрофон кнопкой Test microphone. Обработка не восстанавливает звук, уже перегруженный на входе, и не гарантирует подавление посторонних голосов.

Для проверки в локальной сети распакуйте весь ZIP на серверном ПК, запустите Run_Server.bat и подключите оба клиента к HTTPS-адресу этого ПК. Сверьте отпечаток сертификата с сервером. Первый зарегистрированный пользователь — администратор; второй регистрируется по коду из Administration → Invitations. Аккаунты создаются на вашем сервере, общих предустановленных аккаунтов нет.
