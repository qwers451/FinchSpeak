# Приёмка FinchSpeak на двух ПК

Полная распаковка ZIP обязательна. Скачать установщик и серверный ZIP из одного релиза GitHub. Сервер запускается
через `Run_Server.bat`. Для доступа из интернета пробросить TCP 8443 и UDP 4433;
клиенты подключаются к `https://адрес-сервера:8443`. Сверить отпечаток TLS
с консолью сервера до подтверждения доверия. Первый аккаунт становится админом.
Перед обновлением существующего сервера сохранить БД, `data/` и конфиг.

Каждый пункт требует результата: дата, версии Windows, устройства, ожидаемое и
фактическое поведение. Пустой пункт означает «не проверено».

- [ ] Установка и запуск на обоих ПК; удаление установщика на тестовом ПК.
- [ ] Первый вход с подтверждением отпечатка; повторный вход без предупреждения;
      предупреждение при смене сертификата на отдельном тестовом сервере.
- [ ] Первый админ создаёт приглашение; второй пользователь регистрируется с ним;
      повторное использование одноразового приглашения запрещено.
- [ ] Сообщения, ответы, правка/удаление, реакции, непрочитанные, упоминания,
      поиск по русскому и английскому тексту, вложения и их скачивание.
- [ ] Голос в обе стороны: нет обрезанного первого слова, заметной задержки,
      щелчков, постоянного шума или эха; проверить наушники и колонки.
- [ ] Mute, deafen, push-to-talk при свёрнутом окне, громкость и порог микрофона,
      «слышать себя», смена устройства и отключение гарнитуры во время звонка.
- [ ] Показ монитора и окна: движущаяся картинка, fullscreen, остановка и повторный
      запуск, позднее подключение зрителя, звук экрана и его отдельная громкость.
- [ ] При mute микрофона звук экрана продолжает передаваться. При включённом
      системном звуке учитывается известный захват голосов других участников.
- [ ] Потеря сети и перезапуск сервера: явное состояние переподключения,
      возврат в голос, восстановление просмотра при возобновлении показа.
- [ ] Профиль, аватар и статус обновляются у второго пользователя; модерация,
      server mute, кик, бан и ограничения роли модератора действуют сразу.
- [ ] Закрытие в трей, выход из трея, уведомления, горячие клавиши и настройки
      после перезапуска приложения.
- [ ] Бэкап из админки; остановка отдельного тестового сервера; восстановление
      БД и файлов из копии; аккаунты и история сохранены.
- [ ] Установщик на чистой Windows: WebView2, права, запуск и удаление.
- [ ] Обновление клиента на следующий подписанный релиз (потребуется вторая
      опубликованная версия; первая версия не доказывает весь путь обновления).

Docker-сервер проверяется отдельно на машине с Docker: сборка образа,
`docker compose up`, healthcheck, сохранение данных после пересоздания контейнера.

E2EE, Authenticode, превью ссылок и исключение голосов участников из системного
аудиозахвата не входят в этот релиз по принятым решениям и ограничениям.

## Дополнительная приёмка1.1.0
Автоматические и однопроцессорные стендовые результаты перечислены в [QA-1.1.0](QA-1.1.0.md); они не заменяют следующие физические проверки.
- [ ] На обоих ПК открыть Voice and audio; сравнить Voice enhancement on/off с тихой/обычной/громкой речью. Начать с Input volume100%.
- [ ] Ручной порог не должен отрезать тихие слова; автоматическое усиление следует после детектора речи и само порог не открывает.
- [ ] Назначить PTT, проверить удержание/отпускание в фоне, mute/unmute и Hear myself с наушниками; записанная приватно речь не уходит собеседнику после reopening.
- [ ] Выбрать именованный микрофон/выход, физически отключить/вернуть их и повторно войти в комнату; обработка сохраняет настройку.
- [ ] Сравнить разговор через колонки/наушники, звук демонстрации экрана и два устройства в LAN/NAT; отметить естественность и возможный feedback.
- [ ] После1.0.1→1.1.0 проверить старые настройки и ранее явно выключенный переключатель. Отдельно подтвердить полный автоupdate UI, если он не отмечен PASS в текущем QA.
