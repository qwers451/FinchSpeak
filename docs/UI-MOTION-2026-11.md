Использованы существующие `--ease-out` для входа и `--ease-in` для выхода. Длительности едины в Claude Dark и Finch Custom, тематические цвета и кривые сохранены. У Finch Custom больше нет сокращённого значения 90 мс.

Анимируются только transform и opacity. Свечение задано статическим box-shadow на отдельном слое: сам box-shadow не интерполируется. Не добавлены библиотеки, циклические пульсации, requestAnimationFrame, постоянный will-change, задержки ввода или stagger списков. Цветовые переходы выбранных примитивов заменены мгновенной сменой цвета, чтобы не добавлять покадровую перерисовку фона и границ.

## Reduce motion и взаимодействие

Существующий `prefs.appearance.reduceMotion` применяется store через `data-reduce-motion="true"` на корне. CSS отключает transition/animation у элементов и псевдоэлементов, а также плавный скролл. Та же защита работает независимо через `prefers-reduced-motion: reduce`. Движение кнопок при hover/active тоже отключено: они остаются неподвижными, а обратная связь цветом сохраняется. Индикатор речи виден статически.

Логика Modal не менялась: Esc удаляет окно сразу; при обычном закрытии окно сразу получает inert/aria-hidden, перестаёт перехватывать указатель и возвращает фокус, а затем удаляется через существующие 140 мс. Быстрое повторное открытие отменяет устаревший таймер. При reduceMotion удаление мгновенное. Существующие тесты этих сценариев сохранены. В happy-dom CSS-анимации не исполняются; тесты присутствия Modal продолжают явно проверять его прежний таймер.

## Исправления после ревью (fix 1)

- **Нажатие важнее наведения.** Подъём 1px при hover не применяется к нажатой кнопке (`:not(:active)`), поэтому активная кнопка получает нажатие scale(.98), а не подъём.
- **Курсоры работают.** Убран `pointer-events: none` у `:disabled` и `.is-loading`: курсор `not-allowed` и `progress` теперь виден. Клики блокирует нативное состояние disabled (Button ставит его при loading). Класс `.is-disabled` без нативного disabled сохраняет прежнее поведение.
- **Решения по тостам.** Пауза таймера при наведении и фокусе, сохранение ошибок без таймера и анимированный выход тоста (140 мс) приняты как поведение интерфейса.
- **Действие тоста.** Сначала выполняется action, затем тост закрывается. Повторно добавленный тост с тем же текстом получает тот же id, поэтому дедуплицируется.
- **Нет тестового режима в продукте.** `ToastHost` не проверяет `import.meta.env.MODE`; мгновенное удаление задаётся только reduceMotion или prefers-reduced-motion.
- **Подсказка кнопки.** `title` ставится только кнопкам без видимого текста с `label`.
- Проверено: `app.css` (`.ch .acts button { all: unset }`) загружается раньше `motion.css`, поэтому transition оттуда не сбрасывается; правок не потребовалось.

## Индикатор речи в 1.5.0

Циклические анимации теперь допустимы только для индикатора речи. «Волны» запускают два цикла по 1,4 секунды со сдвигом 0,7 секунды, пока участник говорит. «Пульс», «Эквалайзер» и «Свечение» реагируют на уровень голоса переходами `transform` и `opacity`. «Кольцо» плавно появляется и остаётся статичным. При уменьшении анимации в приложении или системе все варианты отображаются как кольцо без перехода.

Аудио-воркер отправляет уровни раз в 60 мс. В уровень участника попадает максимум из последних трёх кадров по 20 мс, обработанных после предыдущей отправки. Если воркер за один раз обрабатывает больше трёх кадров, учитываются три последних. Пропущенные отчёты не отправляются задним числом. После окончания речи воркер отправляет один пустой список, а уровень отдельного участника сбрасывается после 200 мс без обновления.

### Исключения из правила «только transform и opacity»

- `stroke-dashoffset` у спарклайнов (`.spark polyline`, прорисовка при открытии).
- `clip-path` у перехода темы (`::view-transition-new(root)`).

Ни одно другое свойство разметки (width, height, top, left, margin, padding, gap) в переходах и ключевых кадрах не анимируется: тест `motionLive.test.ts` это проверяет.

### Уменьшение движения

- Все новые анимации отключаются блоками `prefers-reduced-motion: reduce` и `[data-reduce-motion="true"]` в `motion.css` (правила `*`).
- Скриптовые анимации (`popIn`, `rollIn`, `animateLayout`, `rippleAt`) не запускаются при `prefersReducedMotion()`, которая смотрит на `data-reduce-motion` и на системную настройку.
- Переход темы не запускается вовсе, применяется сразу.
- Выход плиток и тостов с удержанием: при уменьшении движения удержание нулевое, элемент исчезает сразу.

### Ограничения и решения

- Птица в `finchspeak-tile.svg` имеет две волны, а не три. Рисунок не менялся, пульсируют эти две (по 200 мс сдвига); третья волна потребовала бы правки иллюстрации.
- Полоса зова и имя над плиткой не сохраняют состояние; они живут только в сессии.
- Для FLIP `animateLayout` сравнивает с позициями, записанными при прошлом вызове: вызывать после каждого изменения порядка. Позиции хранятся относительно комнаты, а после изменения размера окна или комнаты следующий вызов ничего не анимирует (см. 1.7.1).
- Для списков с присутствием (`createPresence`) один ключ дает один стабильный узел: объекты, которые приходят заново, не перезапускают вход.
- Текст счётчиков и значений перекатывается целиком (не по цифрам): так проще и не меняет ширину ячеек.
